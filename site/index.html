GitHub para não desenvolvedores sem escrever uma linha de código.

Curso hands-on de 2 dias pra gente não-técnica (PM, designer, marketing) usar GitHub pra criar, versionar, testar variações e publicar protótipos em HTML. O Dia 1 é todo no navegador, sem instalar nada. No Dia 2 o Claude Code assume a execução, e você segue decidindo.

S O B R E   O   C U R S O

GitHub é a ferramenta. Prototipar é o motivo.

Ninguém aqui vai virar engenheiro. A ideia é sair sabendo criar, versionar, testar variações e publicar protótipos em HTML, usando o Claude pra gerar e editar o conteúdo, e o GitHub pra guardar o histórico, organizar as variações em branches e colocar tudo no ar.

01

Primeiro entender, depois automatizar

O Dia 1 inteiro acontece no navegador, clicando: dá pra ver cada peça do Git antes de pedir qualquer coisa. Só no fim do dia o Claude Code entra, e no Dia 2 ele executa, enquanto as decisões continuam suas.

02

Termina em dupla, como no trabalho

Da metade do Dia 2 em diante, os alunos trabalham em par no mesmo repositório: causam um conflito de verdade, revisam o Pull Request um do outro e constroem duas funcionalidades ao mesmo tempo.

03

Cada bloco com exercício junto

Nada de teoria solta. Cada conceito novo, repositório, branch, conflito, Pull Request, deploy, vem com um exercício prático imediatamente depois, com prompts prontos pra colar.

04

Zero instalação no primeiro dia

Nada de app de Git na máquina. O Dia 1 roda em github.com e claude.ai; o único software que o aluno instala antes é o Claude Code, e só pra usar no último bloco.

"Você não precisa decorar comando nenhum. Precisa entender o que está acontecendo quando cria uma branch, quando ela cruza com outra, e o que significa publicar."

O   M A T E R I A L   D E   E X E M P L O

A ArenaCash não existe. O repositório dela sim.

A ArenaCash é uma fintech inventada pela Product Arena pra servir de cenário. Mas o repositório é real e está no ar: tem histórico de commits, branches abertas, Pull Requests em discussão e um site publicado. É nele que você explora, clona e lê código ao longo do Dia 1, antes de criar o seu.

Exercício 1 · explorar github.com/CaueCM/ArenaCash O repositório: commits, branches e Pull Requests pra clicar sem roteiro Exercício 2 · ler o algoritmo cauecm.github.io/ArenaCash/simulador.html Um simulador de investimento que funciona, e cuja lógica você vai caçar no código O resultado que você vai ter cauecm.github.io/ArenaCash O site publicado: é isso que o seu protótipo vira no fim do Dia 2
